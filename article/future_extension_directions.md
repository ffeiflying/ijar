# IJAR 扩展方向（基于当前 8 页版本）

## 1. 核心实验扩展（优先级最高）
- 消融实验
  - 不同层位点：第1层/中间层/最后层/多层融合。
  - ACF 公式消融：乘积项、最小值项、加权和、带温度参数版本。
  - 证据映射函数消融：`1-exp(-x)`、sigmoid、softplus 映射对比。
- 组件替换实验
  - 正负证据拆分是否必要（仅正证据、仅负证据、双证据）。
  - 不同特征聚合策略：token-level、head-level、channel-level。
- 计算开销对比
  - 与 Self-Consistency / Semantic Entropy 的推理时间、显存、吞吐对比。

## 2. 数据与泛化能力扩展
- 攻击强度控制实验
  - 字体大小、颜色对比度、透明度、位置（中心/边缘）分层评估。
- 场景泛化
  - 从 STA-5K 训练阈值到 RTA-100 测试（zero-shot 阈值迁移）。
  - 加入更多真实场景图片（广告牌、路牌、包装文字、屏幕截图）。
- 多语言攻击
  - 英文之外增加中文、数字混排、符号混排、拼写扰动文本。

## 3. 结果分析扩展（期刊需要更深入）
- 误检漏检分析
  - 典型 false positive：图中本来就有大量正常文字。
  - 典型 false negative：小字号、低对比度、局部遮挡攻击文字。
- 可视化分析
  - 展示被攻击样本在不同层的 ACF 分布变化。
  - 对比不同模型的冲突分布直方图和核密度图。
- 统计显著性
  - 对主要指标做 bootstrap 置信区间。
  - 给出方法间显著性检验（如 DeLong test for AUROC）。

## 4. 工程与部署扩展
- 阈值策略
  - 固定阈值 vs 按模型自适应阈值。
  - 高召回安全模式（宁可误报）与平衡模式两套策略。
- 管线集成
  - 作为前置风险筛查模块：高风险输入触发“拒答/二次验证/OCR复核”。
- API 兼容性讨论
  - 开源权重模型可直接取中间层；闭源 API 的替代方案（黑盒近似指标）。

## 5. 理论与方法可继续推进的点
- 从 DST 角度补充更完整推导
  - ACF 与冲突因子 `kappa` 的关系。
  - ACF 的边界、单调性与稳定性分析。
- 与校准理论结合
  - 研究 ACF 与置信度校准误差（ECE/NLL）的关联。
- 更一般化攻击检测
  - 验证 ACF 是否可迁移到图文越狱、视觉诱导幻觉等任务。

## 6. 建议的论文增页结构（目标约 25 页）
- Introduction + Related Work：4~5 页
- Method（含理论推导）：5~6 页
- Experimental Setup：2~3 页
- Main Results：3~4 页
- Ablation + Robustness：4~5 页
- Analysis + Visualization + Error Study：3~4 页
- Discussion + Limitations + Conclusion：1~2 页
