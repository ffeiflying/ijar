# IJAR 扩刊 → ICCV 方法扩展（2026-10-16）

## 用户确认的顺序

先完成现有 Attention-Level Evidential Conflict 小论文的 IJAR 扩刊，再在经验证的方法基础上发展 ICCV 新工作。当前不切换主任务到 jailbreak 或独立机制论文，不同时启动两套大实验。

## 第一阶段：完成 IJAR

核心问题：ACF在什么任务、模型、层和生成阶段能够可靠发现错误，相比输出置信度有什么独立价值？明确攻击存在检测与回答错误检测的区别。

小论文已包含：ACF公式和注意力后FFN证据化、五模型、STA/RTA、五类基线。上述不能重复称为期刊新增。

期刊新增优先保留：
1. 统一数据划分、严格/语义判分、指标实现和可信主表；补全论文记录与实际实现的对应。
2. 开放回答验证：优先小规模核对RIO的开放回答、答案评分及clean/attack与object/text任务；现有STA/RTA保留与小论文可比的对照。先确认错误数和标注有效，再扩规模。
3. 证据组件对照：conflict vs ignorance及简单内部表征统计，验证DST冲突分量的独立价值。
4. 完整逐层分析、开发集选层/定方向、留出评估，加入prefill与decode分离和答案形式控制。
5. 条件内错误检测与风险覆盖、跨数据迁移、配对置信区间和真实开销。
6. 融合实验作为已完成的机制检验或边界结果，正负结果如实报告；目前不能声称DINO恢复错误可观测性。

不将所有消融都塞入正文。正文围绕定义、主表、选层与组件、freeform泛化、风险覆盖形成证据链；温度、排版因素及更多曲线按价值放附录。修正生成温度写成attention温度、测试集折叠方向、P@R实现等已有问题。

### IJAR 交付顺序

- 第1周：冻结统一评估协议；重算可复用数据；列小论文/期刊新增对应表；核对freeform数据与判分pilot。
- 第2周：只补决定主张的freeform、第二模型基线/组件、跨数据实验；若ACF优势依赖题型或生成后状态，收窄结论。
- 第3–4周：形成完整稿、统计与开销核查、图表独立复算和投稿材料。

这是工作量安排，不是保证四周必投；以关键结论与判分核验完成为准，GPU可用性和标注可能影响进度。

IJAR可投稿检查：主任务定义一致；核心表可复算；与小论文的实质增量明确；无测试集选层/翻方向；至少在明确适用范围内有可靠结果；负结果与边界如实写入。若freeform主要结论失效，先调整主张，不以补模型数量掩盖。

## 第二阶段：IJAR稳定后启动ICCV方法扩展

核心区别：IJAR回答“怎样测、测到了什么”；ICCV候选回答“如何利用可靠的证据诊断改进视觉理解”。ACF不必被证明是通用指标，后续设计应依据它实际有效的范围。

一个优先保留、尚未验证新颖性的候选：基于冲突诊断的按需视觉证据补充与融合。只在特定风险下调取或融合补充视觉表征，保留正常文字读取能力，并证明改进依赖当前图像的有效证据。与现有固定DINO残差融合不同，必须有可验证的新机制；与RIO-RT等选择性读字工作也需逐项区分。

在IJAR阶段只记录有价值现象，不提前写成ICCV贡献。尤其目前wrong-image增益、选项效应仅是pilot线索，不能视作跨模型规律。

### ICCV新工作的必要增量

- 新方法：实际利用诊断信号做条件化干预、证据选择或融合；不是换数据后再次计算同一ACF。
- 新发现：明确干预作用于什么视觉失效，能够通过同预算错图、均值/打乱特征等控制检验。
- 新实证：自由回答、多模型、多任务；对象鲁棒性与正常文字能力同时评估，报告效率与正常任务代价。
- 新颖性审查：EUQ已做jailbreak及逐层分析；VL-Calibration已分离视觉/推理置信度；RIO已研究read/ignore与鲁棒训练。简单复用这些主题不构成新贡献。

### 两篇的边界

小论文、IJAR及未来ICCV之间明确列出继承/新增，引用已公开版本。旧实验可作为起点和对照，不能把相同方法与相同结果重新包装成会议主要贡献。ICCV具体方向在IJAR主要结果稳定后再定，不预先承诺融合或jailbreak一定可行。

## 当前执行优先级

2. 下一份具体产物：IJAR“小论文已有内容—期刊新增证据—缺口”对照表和统一实验协议。
